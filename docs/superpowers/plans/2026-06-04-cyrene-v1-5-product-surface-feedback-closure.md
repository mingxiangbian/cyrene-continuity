# Cyrene v1.5 Product Surface Feedback Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 v1.5 产品面收口：可调用 usage feedback、UI root/source 可见性、保守 duplicate/pollution gates、Automation public surface 去 Dream 泄漏。

**Architecture:** 新增 public feedback write boundary，但继续复用 existing `ActivationEvent` store 和 daily/weekly lifecycle。UI/API 增加 view-only metadata projection，不改 memory store schema。Automation cleanup 只改 public surface 和 adapter shape，内部 `memory-dream*` legacy 暂留。

**Tech Stack:** TypeScript, Vitest, MCP SDK, local JSONL memory store, generated plugin runtime via `npm run build:plugin`.
